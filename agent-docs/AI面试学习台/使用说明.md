# AI 学习台

双击同目录的 `index.html`，选择 Chrome、Edge、Safari 等浏览器打开即可。网页为单文件，题目、答案、样式和脚本全部内置，不需要联网、安装软件或启动服务器。

## 收录内容

- 简单题：151 道，含核心回答、口述版和易错点。
- 中等题：164 道，含核心回答、口述版和易错点。
- 困难题：55 道，含核心回答、口述版和易错点。

没有删除或合并相似题目，也没有复制原网站付费答案。题目 Markdown 文档未修改；答案在独立 Markdown 文件中。

## 使用方法

在左侧目录顶部选择“全部／简单／中等／困难”，下方专题会随之更新。“全部”将各难度题目归入 9 个合并专题；单独选择难度时显示该难度的原有分类。点击题目展开答案。搜索范围是当前难度、分类和状态；默认同时搜索答案全文，多个关键词以空格分开时会匹配全部关键词。搜索不到时可以选择“全部”难度或清除筛选。

星形按钮收藏题目，勾选按钮标记已掌握。“速记”显示口述版和易错点，“完整答案”显示全部内容。每页展示 20 道题；“随机一题”从当前筛选结果里选择。按 `/` 快速进入搜索，按 Escape 清空搜索或关闭手机目录。

收藏、已掌握和阅读偏好只保存在当前浏览器本地。不同浏览器、隐私模式或移动了 HTML 文件后，记录可能不共享；清理浏览器数据也可能丢失记录。建议使用左下角“导出进度”备份，换浏览器后“导入”。导入会保留未出现在备份中的记录，同一题以备份状态为准。

参考资料链接只有主动点击时才会访问外网。网页本身不上传数据，也不调用 AI 服务。

## 后续更新

`index.template.html`、`styles.css`、`app.js` 是页面源文件，`build.mjs` 从同目录上一级的 Markdown 题库生成单文件网页；`data.test.mjs` 校验解析与内容完整性。生成脚本输出 apply_patch 补丁，不直接覆盖文件。

普通阅读只需要 `index.html`。不需要运行开发脚本。
