## easy-58 · 什么是 AI Agent 中的 Skills？它有什么用？

- 难度：简单
- 原始分类：4. AI Agent 原理与设计（25 题）
- 资料类型：原始面试题
- 标签：AI、大模型、Agent、Skills

### 核心回答

Skills 通常指可复用的任务知识与流程包，帮助 Agent 知道某类工作应该如何完成。它可以包含说明文档、步骤、检查标准、示例、脚本和模板，例如“制作财务报告”或“按团队规范审查接口变更”。已有采用 `SKILL.md` 等约定的 [Agent Skills 开放格式](https://agentskills.io/home)，但不同产品支持程度和执行方式仍有差异，不能默认所有系统都使用同一种接口。

工具解决“能做什么”，Skill 更侧重“如何组合能力完成任务”。例如报告 Skill 描述数据口径、图表要求和核验流程，实际读取数据或生成文件仍由工具执行。可以先加载名称和适用范围，任务命中后再读取详细说明及相关资源，减少上下文负担。

工程中应为 Skill 做版本管理、来源审核和适用条件检查。包含脚本时需要在受控环境执行，并验证参数和结果；加载了某个 Skill 不代表自动获得新的工具权限。流程更新后还要跑代表性任务评测，确认没有破坏原来的工作质量。

### 口述练习

Skill 是把任务方法、模板和检查标准做成可复用包，让 Agent 按需加载并执行。它帮助复用经验和降低提示词重复，但格式取决于产品。Skill 提供流程知识，实际操作仍要遵守工具权限和运行时约束。

### 易错点

- Skill 不等于一个工具，也不必然需要独立服务端。
- 说明文档或附带脚本都不能自行扩大用户授权范围。

## medium-86 · 如何设计和管理 AI Agent 的 Skills 体系？在实际项目中有哪些挑战？

- 难度：中等
- 原始分类：4. Agent、协议与 OpenClaw（28 题）
- 资料类型：原始面试题
- 标签：AI、大模型、Agent、Skills

### 核心回答

Skill 应有明确目的、触发条件、输入输出、所需工具、权限、版本与测试。按领域分类，避免能力重叠；加载时只给相关 Skill，防止 Prompt 膨胀。上线前做安全审查、示例回归和变更记录；生产中监控误触发、工具依赖失效、版本冲突与提示注入。高风险 Skill 采用最小权限和人工审批。

### 口述练习

Skills 是可复用的任务能力说明，管理重点是发现、版本、权限、测试和避免冲突。

### 易错点

Skill 文档本身不应自动获得超过用户授权的系统权限。

## concept-agent-skills · Agent Skills 如何通过渐进式加载控制上下文成本？

- 难度：中等
- 原始分类：新概念研读
- 资料类型：补充研读
- 标签：Agent Skills、渐进式加载、SKILL.md、可复用流程
- 来源：[Equipping agents for the real world with Agent Skills](https://www.anthropic.com/research/equipping-agents-for-the-real-world-with-agent-skills)
- 来源日期：2025-10-16；核对日期：2026-11-08

### 核心回答

技能先暴露名称与描述，供智能体判断适用性；选中后读取 SKILL.md 正文；更详细的参考文件在需要时加载。脚本可以通过工具执行，不必把完整实现都加入上下文。

### 口述练习

先看目录，再读相关章节，最后按需看附件或运行脚本。这让技能数量增长时不必把所有内容都预加载。

### 易错点

- 技能文件不等于已经训练进模型。
- 描述不准确会影响技能选择。
- 按需加载仍需要清晰的资源引用与执行边界。
