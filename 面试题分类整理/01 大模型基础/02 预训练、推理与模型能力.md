## easy-3 · 大模型的训练和推理分别是什么？它们在计算资源需求上有什么区别？

- 难度：简单
- 原始分类：1. 大模型基础与核心概念（13 题）
- 资料类型：原始面试题

### 核心回答

**训练**是让模型通过数据学习参数的过程。模型先进行前向计算得到预测，再计算损失，通过反向传播得到梯度，最后由优化器更新参数。预训练、监督微调和偏好对齐都属于训练阶段。

**推理**是使用训练好的参数处理新输入并生成结果。对于自回归大模型，推理通常分为两个阶段：

- **Prefill**：并行处理全部输入上下文并建立 KV Cache，计算量较大。
- **Decode**：逐 Token 生成输出，通常更受显存带宽、KV Cache 和访问延迟影响。

两者的资源差异如下：

| 对比项 | 训练 | 推理 |
| --- | --- | --- |
| 是否更新参数 | 是 | 否 |
| 主要存储 | 权重、梯度、优化器状态、激活值 | 权重、KV Cache、中间状态 |
| 计算特征 | 前向 + 反向，多卡长时间运行 | 前向计算，持续响应请求 |
| 关注指标 | 训练吞吐、稳定性、收敛速度 | 首 Token 延迟、生成速度、吞吐和成本 |
| 典型优化 | 数据并行、张量并行、混合精度、检查点 | 量化、批处理、推测解码、缓存、模型路由 |

单次推理的资源一般远低于训练，但生产系统请求量巨大，长期累计的推理成本也可能超过训练成本。

### 口述练习

训练是通过前向计算、损失、反向传播和优化器来更新模型参数，推理则是固定参数后对新输入生成结果。训练需要保存梯度、优化器状态和激活值，显存与算力开销很大；推理主要保存模型权重和 KV Cache，更关注延迟、吞吐及单位请求成本。

### 易错点

- “推理”在大模型场景中通常表示运行模型，不只是逻辑推理能力。
- 推理不更新参数，但多轮对话会增加上下文和 KV Cache 开销。

## concept-llm-as-rnn · LLM-as-RNN 怎样在不更新权重的情况下进行在线适应？

- 难度：中等
- 原始分类：新概念研读
- 资料类型：补充研读
- 标签：LLM-as-RNN、在线反馈、固定参数、有界记忆
- 来源：[LLM-as-RNN: Feedback-Driven Memory Rewriting for Online Learning and Sequential Prediction](https://aclanthology.org/2026.aacl-long.222/)
- 来源日期：2026-11；核对日期：2026-11-08

### 核心回答

每一步根据当前观察和有限的自然语言记忆预测，接收反馈后改写记忆，再供下一步使用。适应发生在可读的状态更新中，模型参数保持冻结。

论文比较不同反馈来源、记忆预算和推理成本；效果会随任务和基础模型变化。

### 口述练习

让模型把反馈写进下一步要读取的记忆，通过修正状态适应序列，而不是每次重新训练权重。

### 易错点

- 名称类比递归状态，不代表把 Transformer 改造成传统 RNN。
- 反馈不可靠时，记忆更新也可能出错。
- 有限记忆需要选择信息，不能保留全部历史。
