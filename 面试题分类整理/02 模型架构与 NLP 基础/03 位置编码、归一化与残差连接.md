## easy-136 · Transformer 的位置编码是怎样的？

- 难度：简单
- 原始分类：8. Transformer 与 NLP 基础（7 题）
- 资料类型：原始面试题
- 标签：Transformer、位置编码

### 核心回答

标准自注意力的内容匹配本身缺少明确的顺序信息，需要注入位置表示，区分“甲喜欢乙”和“乙喜欢甲”这样的顺序差异。

常见方法包括固定正弦余弦编码、可学习绝对位置嵌入、相对位置表示和旋转位置编码。原始 Transformer 将固定位置编码加到 Token 表示中，经典公式是：

`PE(pos, 2i) = sin(pos / 10000^(2i/d_model))`

`PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))`

可学习位置嵌入直接训练每个位置的向量；相对位置方法强调两个位置的距离。RoPE 对 Q、K 按位置进行旋转，使匹配中包含相对位置信息，见 [RoFormer 原论文](https://arxiv.org/abs/2104.09864)。

例如，同一句话改变词序后，位置表示会改变注意力关系，从而帮助模型区分语义。不同方法的计算方式和长度泛化能力不同；公式可以在更远位置计算，不代表模型一定能可靠处理训练之外的长度。扩展窗口通常还需要模型训练、位置处理与效果评测配合。

### 口述练习

位置编码让注意力知道顺序。原始 Transformer 用正弦余弦编码，其他模型可以使用学习式、相对位置或 RoPE。选型不仅看能否计算长位置，还要验证模型在长距离上的实际效果。

### 易错点

- RoPE 通常作用在 Q、K 上，不是把所有位置向量直接加到输入中。
- 位置编码支持计算更长位置，不等于上下文可无限延长。

## medium-127 · Transformer 中的"残差连接"可以缓解梯度消失问题吗？

- 难度：中等
- 原始分类：7. Transformer、注意力与多模态（24 题）
- 资料类型：原始面试题
- 标签：Transformer、残差连接、梯度消失

### 核心回答

可以。残差把输入直接加到子层输出，形成较短的梯度传播路径，使深层网络更易训练；与 LayerNorm、合理初始化和学习率策略共同改善稳定性。但残差不保证彻底消除梯度消失/爆炸，尤其非常深或训练配置不当时仍可能出问题。Pre-LN 与 Post-LN 的梯度行为也不同。

### 口述练习

残差提供梯度“捷径”，缓解深层训练困难，但还需归一化和优化策略配合。

### 易错点

不能把残差理解成“梯度恒等于 1”。

## medium-135 · 了解 LLaMA 中的旋转位置编码吗？

- 难度：中等
- 原始分类：7. Transformer、注意力与多模态（24 题）
- 资料类型：原始面试题
- 标签：自然语言处理（NLP）、大语言模型、旋转位置编码

### 核心回答

RoPE 将位置相关的旋转施加到注意力中的 Q、K 成对维度上，使两位置的点积自然携带相对位置信息。它不需要把绝对位置向量直接加到 Token 表示中，适合自回归 Transformer；不同 LLaMA 版本可能调整频率、缩放和上下文策略。RoPE 有利于建模相对位置，但超出训练长度的外推质量仍需实测。

### 口述练习

RoPE 通过旋转 Q/K 编码位置，使注意力分数感知相对距离。

### 易错点

RoPE 不是让模型天然支持无限长度上下文。

## medium-138 · Transformer 为什么采用 Layer Normalization 而不是 Batch Normalization

- 难度：中等
- 原始分类：7. Transformer、注意力与多模态（24 题）
- 资料类型：原始面试题
- 标签：Transformer、normalization

### 核心回答

LayerNorm 在单个样本的特征维度上归一化，不依赖同一批次其他样本，适合长度变化、Mask、自回归推理和小批量/在线生成。BatchNorm 依赖批统计，训练与推理行为不同，序列长度和分布变化时较麻烦。LayerNorm 与残差共同改善深层训练稳定性；部分现代模型采用 RMSNorm 等变体，不能说所有 Transformer 都只用 LayerNorm。

### 口述练习

LayerNorm 不依赖 batch 统计，更适合变长序列和逐 Token 推理。

### 易错点

不要把 LayerNorm 说成“沿序列长度归一化”；通常是沿每个 Token 的隐藏特征维度。
