## medium-129 · 了解 ViT（Vision Transformer） 吗？

- 难度：中等
- 原始分类：7. Transformer、注意力与多模态（24 题）
- 资料类型：原始面试题
- 标签：Vision Transformer

### 核心回答

ViT 把图像切成固定大小 patch，线性映射为 Token，加位置编码后交给 Transformer Encoder，使用分类 Token 或池化结果做图像分类。它把视觉问题转成序列建模；优势是可扩展和全局关系建模，但对数据规模、分辨率和计算资源较敏感。注意图像 patch 数随分辨率增大，标准自注意力成本大致随 Token 数平方增长。

### 口述练习

ViT 把图片切块当 Token，交给 Transformer 编码，再用聚合表示分类。

### 易错点

ViT 不是先用 CNN 抽全部区域特征的架构；原始 ViT 直接用 patch 投影。

## medium-130 · ViLT 模型是如何将 Transformer 应用于图像识别任务的

- 难度：中等
- 原始分类：7. Transformer、注意力与多模态（24 题）
- 资料类型：原始面试题
- 标签：ViLT、图像识别

### 核心回答

题目表述不够准确：ViLT 是视觉—语言预训练模型，主要面向图文匹配、视觉问答等跨模态任务，不是单纯图像分类模型。它将图像切成 patch、文本分成 Token，一起送入 Transformer 做跨模态交互，尽量省去昂贵的预训练视觉区域检测器。训练可用图文匹配、掩码语言建模及词—图块对齐等目标。

### 口述练习

ViLT 把图像 patch 与文本 Token 共同输入 Transformer，重点是图文融合，而非传统单图识别。

### 易错点

不要把 ViLT 与 ViT 混淆；前者是图文模型，后者主要是视觉编码器。

## hard-14 · LLM Agent 在多模态任务中如何执行推理？

- 难度：困难
- 原始分类：2. Agent、推理与框架（16 题）
- 资料类型：原始面试题
- 标签：大模型、AI、Agent

### 核心回答

先识别输入模态并做预处理：图片/视频抽帧与 OCR，音频转写并保留时间戳，文本规范化；再将可用内容交给支持相应模态的模型，或调用专用视觉、语音、检索和计算工具。Agent 把目标拆成可校验步骤，例如“读图表→提取数值→代码计算→生成解释”，每步保留来源坐标/时间。对跨模态实体对齐、时序关系、图像幻觉和隐私做专项评测；关键结论回查原媒体。

### 口述练习

多模态 Agent 是感知、工具、推理和验证的闭环；要保留图像区域或音频时间戳作为证据。

### 易错点

单纯把图片路径写进 Prompt 不等于模型看到了图片。

## hard-44 · 了解 ViLT（Vision-and-Language Transformer）吗？

- 难度：困难
- 原始分类：4. 模型原理、NLP 与部署选型（12 题）
- 资料类型：原始面试题
- 标签：ViLT

### 核心回答

ViLT 是图文联合预训练架构，将图像直接切成 patch、文本分成 Token，一起输入 Transformer，让计算重点从昂贵的视觉区域特征提取转向跨模态交互。常见训练目标包括图文匹配、掩码语言建模和词—图块对齐；可用于视觉问答、图文检索等任务。它不同于只做图像分类的 ViT，也不意味着完全不做视觉预处理。实际性能受图像分辨率、对齐数据质量和任务类型影响。

### 口述练习

ViLT 通过图像 patch 与文本 Token 的统一 Transformer 表示，高效学习图文关系。

### 易错点

不要把 ViLT 说成纯文本 LLM 或单纯的图像识别模型。
