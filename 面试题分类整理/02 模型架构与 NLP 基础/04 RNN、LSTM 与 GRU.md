## easy-138 · 说说 LSTM 的基本原理。

- 难度：简单
- 原始分类：8. Transformer 与 NLP 基础（7 题）
- 资料类型：原始面试题
- 标签：自然语言处理（NLP）、LSTM

### 核心回答

LSTM 是一种带门控和细胞状态的循环网络，用于缓解普通 RNN 学习长距离依赖时的梯度问题。常用版本同时维护细胞状态 `c_t` 和隐藏状态 `h_t`，用门控制信息保留、写入和输出。

- **遗忘门**决定上一时刻的哪些信息继续保留。
- **输入门**控制候选信息写入多少。
- **输出门**控制细胞状态中哪些信息形成当前输出。

典型更新形式为：

`c_t = f_t ⊙ c_(t-1) + i_t ⊙ g_t`

`h_t = o_t ⊙ tanh(c_t)`

加法状态路径有利于信息和梯度沿时间传播，但门值与训练条件仍会影响记忆长度。原始 LSTM 与后来加入遗忘门的工作分别见 [1997 年论文](https://www.bioinf.jku.at/publications/older/2604.pdf) 和 [Learning to Forget](https://doi.org/10.1162/089976600300015015)。

例如，情感分类时可以保留句子开头的否定信息，避免只依据末尾积极词判断。它仍需依次处理状态，长序列训练效率和记忆能力有边界，并未彻底解决所有梯度消失、爆炸和信息遗忘问题。

### 口述练习

LSTM 通过细胞状态和门控选择保留、写入及输出的信息，加法路径帮助缓解长距离梯度问题。它比普通 RNN 更容易学习长期依赖，但仍是循环结构，训练并行和记忆长度仍有限。

### 易错点

- 隐藏状态与细胞状态不同，不能将两者混为同一个变量。
- LSTM 缓解梯度问题，并不是数学上保证永不消失或爆炸。

## medium-148 · 请解释 LSTM 和 GRU 网络在处理序列数据中的应用。

- 难度：中等
- 原始分类：8. NLP、序列模型与词表示（17 题）
- 资料类型：原始面试题
- 标签：自然语言处理（NLP）、LSTM、GRU

### 核心回答

LSTM 和 GRU 都是带门控的循环网络，逐步读取序列，通过门控保留或遗忘历史信息，常用于文本分类、序列标注、时间序列预测和较小数据场景。LSTM 有独立 cell state 与更多门，表达灵活；GRU 结构较简洁、参数通常较少。它们比普通 RNN 更能处理长距离依赖，但顺序计算不易并行，极长文本通常还需注意力或 Transformer。

### 口述练习

两者都用门控控制信息流，适合时序任务；LSTM 更复杂，GRU 更轻量。

### 易错点

门控缓解长依赖问题，不代表能无损记住任意长度序列。

<a id="medium-150"></a>

## medium-150 · LSTM 和 GRU 有什么区别？

- 难度：中等
- 原始分类：8. NLP、序列模型与词表示（17 题）
- 资料类型：原始面试题
- 标签：自然语言处理（NLP）、LSTM、GRU

### 核心回答

LSTM 通常有输入门、遗忘门、输出门，以及独立的 cell state 和 hidden state；GRU 常用更新门、重置门，通常没有独立 cell state，状态更新更紧凑。GRU 参数更少、训练可能更快，LSTM 在一些复杂长依赖任务上可能更有表达余地。没有稳定的“谁一定更好”，应在相同数据、参数预算和训练设置下实测。

### 口述练习

LSTM 有三门和双状态，GRU 有两门、状态更简洁；选择主要看业务数据和效率。

### 易错点

GRU 不是“简化版但必然更差”的 LSTM。

## medium-151 · 解释一个 LSTM 单元（LSTM cell）的基本组成，以及它们各自的作用。

- 难度：中等
- 原始分类：8. NLP、序列模型与词表示（17 题）
- 资料类型：原始面试题
- 标签：自然语言处理（NLP）、LSTM

### 核心回答

LSTM 单元接收当前输入、上一隐藏状态和上一单元状态。遗忘门决定保留多少旧 cell 信息，输入门控制候选新信息写入，输出门决定从更新后的 cell state 暴露多少到 hidden state；候选状态提供可写入内容。门值一般由 sigmoid 产生，候选状态常用 tanh。加性 cell 更新让信息与梯度更容易跨时间传播。

### 口述练习

遗忘门删旧信息、输入门写新信息、输出门生成当前可见状态；cell state 是长期通道。

### 易错点

不要把三门都理解为互斥开关，它们是连续权重。

## medium-152 · LSTM 中，隐藏状态（hidden state）和单元状态（cell state）有什么区别？

- 难度：中等
- 原始分类：8. NLP、序列模型与词表示（17 题）
- 资料类型：原始面试题
- 标签：自然语言处理（NLP）、LSTM

### 核心回答

Cell state `c_t` 是沿时间传播的内部记忆通道，通过遗忘与输入门进行加性更新；hidden state `h_t` 是当前时刻对外输出的表示，通常由输出门调节 `tanh(c_t)` 得到，并用于下一步门计算。两者维度常相同，但作用不同：`c_t` 更偏长期存储，`h_t` 更偏当前可见摘要。

### 口述练习

`c_t` 是内部记忆，`h_t` 是对外暴露的当前表示；输出门决定记忆能显示多少。

### 易错点

不能把 `h_t` 与 `c_t` 当成同一个变量。

<a id="medium-160"></a>

## medium-160 · 与循环神经网络（RNN）相比，LSTM 是如何解决梯度消失问题的？

- 难度：中等
- 原始分类：8. NLP、序列模型与词表示（17 题）
- 资料类型：原始面试题
- 标签：自然语言处理（NLP）、LSTM、RNN、梯度消失

### 核心回答

普通 RNN 反向传播要连续乘多步 Jacobian，容易让梯度指数衰减；LSTM 的 cell state 采用受门控的加性更新，提供较直接的信息与梯度通道，遗忘门可学习保留重要内容。因此能显著缓解长依赖问题。它并不彻底“解决”所有梯度消失，极长序列、门饱和或参数不佳仍可能使训练困难。

### 口述练习

LSTM 用门控和加性 cell 通道，让梯度更容易跨时间传播，比普通 RNN 更能记长信息。

### 易错点

不要说 LSTM 永远不会梯度消失。
